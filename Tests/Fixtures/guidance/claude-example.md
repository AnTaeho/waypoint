# 예시 프로젝트 — 작업 지침

만든 예시다. 실제 사용자 파일을 옮기지 않았다.

## 규칙

- 앱은 외부 API를 부르지 않는다.
- 훅은 1초 안에 끝낸다: 실패해도 exit 0.
  - 표준 출력은 시작 훅에서만 쓴다.
  - 시간 초과는 조용히 넘긴다.
    - 기록은 로그 파일에만 남긴다.
- 카드를 자동으로 닫지 않는다.

## 순서

1. 조사 — 코드를 읽는다.
2. 결정 — 사용자가 정할 것은 묻는다.
3. 계획
   - 단계마다 파일, 이유, 검증.

| 일 | 누가 |
|---|---|
| 판단 | 메인 |
| 손 | 일꾼 |

## 명령

```sh
swift test --filter Guidance
- 이 줄은 목록이 아니다
```
