# Waypoint 제품 로드맵

상위 카드 TRK-9. 카드별 완료 조건은 Waypoint 보드(TRK)에 있다.

## 승리 조건

첫 고객은 Claude Code·Codex로 여러 프로젝트를 만드는 Mac 개인 개발자다. 기록 정리와 맥락 재설명에 드는 시간을 줄이고, 어디까지 검증됐는지 보이게 한다.
핵심 경험: 작업 → 정확한 기록 → 중단 → 도구를 바꿔 재개 → 근거를 보고 완료 판단.
Jira도 AI 에이전트·MCP 연결로 가고 있어 연동 자체는 차별점으로 내세우지 않는다. Waypoint의 우위는 아직 가설이다.

## 단계

| 단계 | 카드 | 다음으로 가는 조건 | 상태 |
|---|---|---|---|
| A. 믿고 이어 가는 개인 제품 | TRK-10~12 | 근거·기록 신뢰성·재개 검증 | 완료 |
| B. 외부 사람이 설치하고 사용 | TRK-13~15 | 10명 2주 사용 관찰, 같은 과제 비교 | TRK-15 남음 |
| C. 돈을 내고 계속 쓰는 제품 | TRK-19·20 | 상위 문제 해결, 가격 실험, 유료 파일럿 | 아이디어 |
| D. 소규모 팀 | TRK-21 | 개인판 반복 사용·지불, 팀 수요 | 아이디어 |

## 목표 수치(내부 판단용)

- 설치: 처음 쓰는 10명 중 7명이 도움 없이 5분 안에 첫 카드 연결.
- 재개: 중앙값 60초 이내, 기존 방식보다 50% 단축. 복사 버튼 클릭은 재개 성공으로 세지 않는다.
- 반복 사용: 첫 연결한 10명 중 6명이 2주차에 3일 이상 사용. 이탈자를 분모에서 빼지 않는다.
- 신뢰성: 재수신·폴더 전환·도구 변경·복수 세션·잠자기·재시작에서 누락·중복·오귀속 0건, 수신→표시 p95 2초.
- 지불: 유료 사용자 3명, 그중 4주 뒤에도 쓰는 사람 2명. 설문상 구매 의향은 지불로 세지 않는다.
- 측정은 로컬 우선. 대화·소스 원문은 기본으로 모으거나 보내지 않는다.

## Jira 기능을 담는 방향(2026-10-02 사용자 결정)

Jira 연동은 하지 않는다. Jira가 하는 일을 Waypoint 안에 담되 사람 입력 대신 에이전트 기록으로 채운다.

| 카드 | 담을 기능 | 상태 |
|---|---|---|
| TRK-58 마일스톤 | 목표일과 묶인 카드, 근거 기반 진행률 | 아이디어 |
| TRK-59 카드 관계와 라벨 | 막힘·관련·중복, MCP로도 건다 | 아이디어 |
| TRK-54 기록 기반 보고서 | 처리 시간·진행 현황·주간 일지 | 아이디어 |
| TRK-61 알림 | 막힘·오래 멈춤 | 아이디어 |
| TRK-57 카드에서 에이전트 작업 맡기기 | 에이전트 배정 | 「앱은 작업을 자동 실행하지 않는다」 원칙을 바꿀지 사용자 결정 대기 |

취소: TRK-16 계획(사람 입력 계획 기능), TRK-18·50~52 Jira 연동, TRK-60 검색·필터.

## 다음 일 고르기

1. 이어 가라고 하면 이 문서와 TRK-9 하위 카드부터 읽고, 선행 조건을 충족한 가장 앞 번호의 미완료 카드를 시작한다. 매번 다음 일을 묻지 않는다.
2. 기록 손실·데이터 손상·오귀속은 기능 작업보다 먼저 고친다.
3. 참여자·관찰 결과·실제 지불이 없는 카드는 완료 처리하지 않는다.
4. 외부 초대 발송·과금·공개 출시는 그 행동을 명시적으로 지시받았을 때만 한다.

## 범위

Mac 우선, Claude Code·Codex 우선. 모바일 새 기능, 모든 AI 연결, 대기업 권한 체계, 범용 스프린트는 초기 범위에서 뺀다. 데이터 내보내기는 제공하고, 기록을 묶어 두는 것을 경쟁력으로 삼지 않는다.
