## 1. 설치

**필요한 것**
- macOS 14 이상(Apple 실리콘·Intel 모두)
- Claude Code나 Codex 중 하나 이상. 이미 로그인해서 쓰고 있어야 해요.

**순서**
1. 받은 [파일 이름].zip을 풀고 `Waypoint.app`을 「응용 프로그램」 폴더로 옮겨요.
2. Waypoint를 열면 「Waypoint 연결」 창이 떠요.
3. 쓰는 도구(Claude Code·Codex)를 고르고 「연결」을 누르면, 바뀌는 설정 파일 목록이 보여요. 확인하면 연결돼요.
4. Codex를 쓴다면 Codex를 새로 열고 `/hooks`에서 Waypoint를 신뢰해 주세요. Codex는 사용자가 직접 허락한 연결만 돌려요.
5. 진행 중인 프로젝트 폴더를 하나 골라 등록해요.
6. 그 폴더에서 Claude Code나 Codex로 평소처럼 작업을 시작하면 「첫 기록」이 확인되고, 「끝」을 누르면 설치가 끝나요.

창을 닫았다가 다시 열고 싶으면 메뉴 막대의 Waypoint 아이콘 → 「연결 설정…」을 고르면 돼요.

**연결할 때 바뀌는 것**
- Claude Code: `~/.claude/settings.json`에 Waypoint 기록 연결 추가, 상태줄이 있으면 그 명령을 감싸서 사용량을 읽음(원래 상태줄은 그대로 보임), `~/.claude/skills/tracker/` 추가, Waypoint를 Claude Code 도구로 등록.
- Codex: `~/.codex/hooks.json`·`~/.codex/config.toml`에 Waypoint 연결 추가, `~/.agents/skills/waypoint-tracker/` 추가.
- 바꾸기 전 원래 파일은 `~/Library/Application Support/Waypoint/integration-backups/`에 백업돼요.

## 2. 쓰는 동안

- Waypoint는 메뉴 막대에 떠 있어요. 창을 닫아도 계속 기록해요.
- 프로젝트마다 카드 보드가 생기고, 작업 중인 세션·마지막 요청·바뀐 파일·검증 결과가 카드에 쌓여요.
- 이어서 하던 일은 카드에서 「재개 문맥 준비」를 눌러 새 대화에 붙일 문맥을 복사하거나, 그 도구로 바로 열 수 있어요.
- 연결이 이상해 보이면 툴바의 연동 상태 버튼에서 도구별 상태와 마지막 수신 시각을 볼 수 있어요.

## 3. 알려진 제한

- **Mac을 다시 켜면 Waypoint를 직접 열어 주세요.** 로그인할 때 자동으로 열리지 않아요. 꺼져 있는 동안의 기록은 쌓여 있다가 다음에 열 때 들어와요. Claude Code·Codex는 Waypoint가 꺼져 있어도 평소처럼 동작해요.
- **Claude Code는 연결한 뒤 새로 연 세션부터 기록돼요.** 이미 열려 있던 세션은 다시 시작해야 해요.
- **iCloud 동기화는 베타에서 쓰지 않아요.** 기록은 그 Mac에만 남아요. iPhone 앱도 베타에 들어 있지 않아요. *(운영자: iCloud 운영 환경을 배포했으면 이 줄을 고친다.)*
- **등록한 폴더 밖에서 시작한 세션은 프로젝트에 붙지 않을 수 있어요.** 카드 보드에 안 보이면 그 폴더를 등록하거나, 대화에서 `/tracker`로 프로젝트를 이어 주세요.
- **카드를 자동으로 완료하지 않아요.** 완료는 직접 표시해요.
- 요청 문장은 30일 뒤 지워지고, AI 답변·대화 전체·명령 출력은 처음부터 남기지 않아요. 무엇이 남는지는 설정(⌘,) → 「기록」에서 볼 수 있어요.

## 4. 그만 쓰거나 지우기

1. 메뉴 막대 Waypoint → 「연결 설정…」 → 도구마다 「연결 해제」. 설정 파일에서 Waypoint 항목만 빠지고 원래 설정은 그대로예요.
2. 기록도 지우려면 설정(⌘,) → 「기록」 → 「모든 기록 지우기…」. 지우기 직전 백업이 하나 남아요.
3. Waypoint를 끄고 `Waypoint.app`을 휴지통으로 옮겨요.
4. 남은 파일까지 정리하려면 아래 폴더를 지워요.
   - `~/Library/Application Support/Waypoint/` (백업·연결 상태)
   - `~/.claude/waypoint/`, `~/.codex/waypoint/` (연결 해제 뒤에도 열린 세션을 위해 남겨 둔 작은 스크립트)

## 5. 문제 알리기

문제가 생기면 아래 양식을 채워 [받는 곳]으로 보내 주세요. 대화 내용이나 코드는 보내지 않아도 돼요.

```
언제: (날짜·시각)
무엇을 하다가:
기대한 것:
실제로 일어난 것:
다시 해도 같은가: 예 / 아니오 / 모름
쓰는 도구와 버전: Claude Code ___ / Codex ___
macOS 버전:
진단 정보: (아래 방법으로 복사해 붙여 넣기)
화면 캡처: (있으면. 프로젝트 이름·코드가 보이면 가려 주세요)
```

**진단 정보 복사**: 툴바의 연동 상태 버튼 → 「진단 정보 복사」. 앱 버전, 연결 상태, 마지막 수신 시각, 기록 지연·설치 단계 같은 숫자만 들어 있어요. 대화·요청 문장·파일 경로는 들어 있지 않아요.
