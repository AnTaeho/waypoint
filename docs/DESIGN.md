# 디자인

원본 캔버스: https://claude.ai/artifact/G9JsAmHhuKb1ZLeRdoroGM

`design/*.dc.html`은 캔버스 전용 런타임으로 그려지는 마크업이라 브라우저에서 단독으로 열리지 않는다. **레이아웃 구조, 인라인 스타일 값, 문구를 읽는 용도**로 쓴다. SwiftUI로 옮길 때 픽셀 단위 복제보다 구조와 토큰을 따른다.

## Mac 창 틀

- `NavigationSplitView` 두 칸 + 오른쪽 `inspector`. 창 틀을 직접 그리지 않는다(신호등 버튼, 툴바는 시스템 것).
- 사이드바: 시스템 사이드바 목록. 항목은 대시보드, 그 아래 「프로젝트」 구역에 프로젝트 이름 + 작업중 개수(점과 숫자). 배경 `sidebar`. 아이콘 색은 `liveText`.
- 툴바: 화면 이름, 검색 필드(`.searchable`), 프로젝트 등록(+), 인스펙터 토글.
- 목록은 표 형태: 열 머리 11pt semibold `textMuted` + 아래 구분선, 행 높이 32–34, 프로젝트별 그룹 머리 11pt semibold. 강조할 행(작업중)만 `surface` 배경.
- 최근 기록·카드 정보처럼 곁들이는 정보는 인스펙터(`bgPanel`, 너비 약 300).
- 페이지 제목은 본문 맨 위 나눔스퀘어라운드 B 26. 툴바 제목과 겹쳐도 된다(툴바는 화면 이름, 본문 제목은 상황 문장).
- 앱 accent 색은 `liveText`.
- 사이드바 맨 아래 사용량 게이지 두 줄: 「5시간」「7일」 캡션 + 높이 4 캡슐 막대(채움 `live`, 바탕 `gaugeTrack` 12%) + 오른쪽 「42%」. 80% 이상은 막대·숫자를 `liveText`로 진하게, 30분 넘은 기록은 전체 불투명도 0.45, 기록이 없으면 영역을 숨긴다. 초기화 시각은 마우스를 올렸을 때만(「오후 3:20에 초기화」).

## iPhone

한 화면(`iOS/RootView`, `NavigationStack`), 내비게이션 막대는 숨긴다. 좌우 여백 18, 구역 사이 18.

- 머리: 날짜(「9월 28일 일요일」 13 `textMuted`) 아래 제목 「작업중 N」(N = live 줄 수, 없으면 「진행 중인 작업 없음」), 나눔스퀘어라운드 B 30. 개발용은 날짜 줄 오른쪽에 「Dev」.
- 작업중: Mac 대시보드와 같은 줄(`DashboardQuery`) 하나가 카드 한 장. 프로젝트 순서대로 이어 놓고(live 있는 프로젝트 먼저, 이름순) 프로젝트 이름은 카드 윗줄에 둔다. 윗줄 「LDG-14 · 가계부 앱」(모노 11 `textMuted`) + 오른쪽 경과(12 B `liveText`) 또는 「멈춤 N분」(12 `textMuted`), 제목 15 B, 아랫줄 「sess·7f2a · ReceiptParser.swift」(모노 11 `textSecondary`). live는 `live` 1.5pt 테두리와 펄스 점, 멈춤은 `border` 1pt와 속 빈 점. 서브에이전트 줄은 16 들여쓴다. 카드 없는 세션은 윗줄에 프로젝트 이름만, 제목 자리에 「카드 없음」(15 R `textMuted`), 누를 수 없다. 카드 사이 10, 안쪽 여백 14, 모서리 14, 흰 바탕.
- 방금 기록된 아이디어: 구역 제목 14 B. 최근 7일에 생긴 idea 상태 카드(`IdeaInbox`, 새것부터). 점선(`ideaBorder` 1.5, 5·3) `bgPanel` 카드에 「LDG-21 · 18분 전」, 제목, 알약 버튼 「다음 할 일로」「보관」(높이 36, 13 B, 흰 바탕·`border`). 누르면 바로 옮기고 목록에서 빠진다.
- 카드를 누르면 상세(읽기 전용): 「LDG-14 · 가계부 앱 · 다음 할 일」, 제목 22 B, 본문 15, 「완료 조건 1/3」과 체크 표시(`checkmark.square` `done` / `square` `textMuted`, 끝난 것은 취소선).
- 시간 표시는 30초마다 다시 그린다(`TimelineView`). 당겨서 새로고침은 없다(동기화가 알아서 온다).
- 토큰은 `Theme.Phone`.

## 앱 아이콘

이정표(푯말 두 개). 평소용은 클레이(`live`) 바탕에 흰 푯말, 개발용은 검은 바탕에 클레이 푯말. 원본 `design/icon/*.svg`.

## 화면 문구

- 설명서 말투, 동작 규칙, 만든 쪽 용어(훅·MCP·스킬·세션 요약 등)를 화면에 쓰지 않는다. 시안에 있는 「Claude가 남긴 것」, 「대화에서 감지」, 「세션 종료 시 자동 작성」, 「새 세션을 열어 …」 같은 문구는 옮기지 않는다.
- 세션 ID·서브에이전트 이름·파일명처럼 사실만 짧게 보인다.

### 타이포

- 제목·본문·UI: 나눔스퀘어라운드(NanumSquareRound). 한글까지 둥글게 그려지는 서체라 번들한다. 시스템 둥근 서체(SF Pro Rounded)에는 한글 글리프가 없다.
- 굵기 대응: 본문 regular → R, medium·semibold → B, 페이지 제목·카드 상세 제목 → B. L·EB는 번들만 하고 쓰지 않는다. 가짜 볼드 금지.
- 카드 ID, 세션 ID, 경로, 파일명: 모노 (SF Mono). 그대로 둔다.
- 크기(macOS): 페이지 제목 26, 카드 상세 제목 28, 섹션 13, 본문 13, 표 머리·캡션 11, 큰 캡션 11.5, 카드 제목 14. 크기는 고정(Dynamic Type 미적용).
- 새 프로젝트 등록 창: 제목 26(B), 입력 14, 이름표 12(`textSecondary`), 입력 칸 높이 36·모서리 8, 키 칸 폭 110, 상자 제목 13(B). `Theme.Init`.
- 지침 문서 읽기: 제목 1·2·3단계 22·17·14.5(B), 본문 13.5, 인라인 코드 12.5 모노, 코드 블록 12 모노, 편집기·비교 원문 12.5 모노. `Theme.Guide`.
- 큰 캡션만 12에서 11.5로 줄였다. 이 서체는 숫자 폭이 고정이라 「12분째」 같은 경과 시간이 SF보다 넓다.
- 파일: `App/Fonts/NanumSquareRound{L,R,B,EB}.ttf`, 라이선스 `App/Fonts/OFL.txt`(SIL OFL 1.1, NAVER). 앱 시작 시 `FontRegistry`가 프로세스 범위로 등록하고, 등록에 실패하면 시스템 폰트로 그려진다.

### 형태

- 모서리: 카드 10, 패널 12–14, 버튼 8, 배지 캡슐.
- 작업중 카드: 1.5pt `live` 테두리 + 옅은 그림자. 서브에이전트 카드는 부모 아래 14pt 들여쓰기.
- 작업중 점: 8pt 원, 1.8초 주기 펄스(바깥으로 퍼지는 링).
- 이모지·그라디언트 사용 안 함. 아이콘은 SF Symbols 선형.
