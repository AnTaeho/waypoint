# 디자인

원본 캔버스: https://claude.ai/artifact/G9JsAmHhuKb1ZLeRdoroGM

`design/*.dc.html`은 캔버스 전용 런타임으로 그려지는 마크업이라 브라우저에서 단독으로 열리지 않는다. **레이아웃 구조, 인라인 스타일 값, 문구를 읽는 용도**로 쓴다. SwiftUI로 옮길 때 픽셀 단위 복제보다 구조와 토큰을 따른다.

## PC 통합 대시보드 개편 (2026-09-30)

`design/Dashboard-desktop-preview.html`은 브라우저에서 단독으로 여는 승인 시안이다. 기존 프로젝트 보드와 iPhone 화면은 유지한다.

- 상단: 작업 중·멈춤(열린 카드 연결과 카드 없는 메인 세션 줄 수), 다음 할 일(카드 수), 오늘 완료(현재 done이며 로컬 날짜의 자정부터 지금까지 완료된 카드 수). 검색·에이전트 필터와 무관한 전체 집계.
- 중앙: 진행 중인 작업 타일, 전체/Claude/Codex 필터. 카드 제목·ID, 프로젝트, 도구·세션, 최근 파일, 경과. 하위 작업은 같은 부모가 보이는 경우 들여쓴다. 카드가 있으면 기존 상세로, 카드 없는 세션은 읽기만.
- 오른쪽: 멈춘 작업, 미완료 카드의 다음 세션 메모(최근 수정순 최대 3개), 접힌 최근 기록(최대 3개). 멈춤은 실패·응답 대기를 뜻하지 않는다.
- 아래: 최근 활동순 프로젝트 카드. 이름·개요·작업 중/멈춤/다음/아이디어 수·폴더·마지막 활동. 누르면 기존 프로젝트 보드로 이동.
- 본문 가용 폭 780 이상이면 작업/이어가기 두 열, 좁으면 위아래로 배치한다. 프로젝트 카드는 최소 210으로 자동 줄바꿈한다.
- 통합 화면의 기록 인스펙터는 닫힌 채 시작하고 툴바로 켤 수 있다. 카드 상세·프로젝트 보드의 인스펙터 상태와 별도로 유지한다.
- 프로젝트 이름·키로 검색하면 해당 프로젝트 작업을, 카드 제목·ID나 카드 없는 세션의 요청 문장으로 검색하면 해당 작업을 보여준다. 데이터가 없거나 검색 결과가 비면 빈 상태 문구를 표시한다.

## 카드 상세 완료 근거 (2026-10-01, TRK-10)

- 완료 조건 줄: 체크 상자와 조건 글 오른쪽에 근거 상태 한 마디(큰 캡션 11.5). 「통과 · 확인됨」「실패 · 보고」「미검증」「변경 후 미검증 · 확인됨」「건너뜀 · 보고」. 색은 통과 `done`, 실패 `liveText`(`Theme.Evidence.fail`, 따뜻한 계열 유지), 나머지 `textMuted`. 통과·실패는 B, 미검증·변경 후 미검증은 R. 마우스를 올리면 명령과 시각(변경 후 미검증이면 「이전 결과 통과」 한 줄 더). 체크 상자는 사용자 판단 표시로 그대로 두고 근거 상태와 섞지 않는다.
- 「검증 기록」 구역(완료 조건 아래, 히스토리 위, 기록이 없으면 그리지 않음): 최근 것부터 8줄, 넘으면 「N개 더」 링크. 줄: 결과(통과·실패·결과 모름·건너뜀, 폭 64, 결과 색) + 명령(모노 12, 한 줄, 가운데 생략, 마우스를 올리면 전체) + 오른쪽 캡션 「조건 1 · 확인됨 · 이후 변경 · 14:02」(조건 번호·이후 변경은 있을 때만, 마우스를 올리면 보고의 짧은 사실).
- 히스토리에도 「검증 통과 · 확인됨」「조건 2 검증 실패 · 보고」 줄(명령 앞 60자 모노)이 남는다. 활동 탭은 명령 + 같은 문구.
- 보드 카드·대시보드·iPhone에는 넣지 않았다(이번 범위 밖).

## 카드 재개 (2026-10-01, TRK-12)

- 카드 상세 「작업 이어가기」 영역: 제목 줄(「재개 문맥 준비」 버튼) 아래 재개 상태 한 줄(큰 캡션 11.5) 「준비됨」「복사함 · Codex 새 세션 연결 전」「연결됨 · Codex 새 세션」「연결 끊김 · Codex」「재개 불가 · 완료한 카드」. 연결됨만 `done`, 나머지 `textMuted`. 그 아래 메모 작성 시점과 메모 세 줄(그대로).
- 재개 창(720×640, `Theme.Resume`): 제목 → 요약 묶음(`bgPanel`, 반경 12, 안쪽 14) → 접힌 「복사할 문맥」(펼치면 모노 12, `bgSunken`) → 도구 고르기 → 작업 폴더(모노) → 재개 상태 한 줄 → 버튼 줄. 요약과 문맥은 같이 스크롤한다.
- 요약 묶음은 두 칸 표: 왼쪽 이름(큰 캡션 B, `textMuted`, 폭 76) 「목표」「남은 조건 N」「미검증 N」「메모」, 오른쪽 내용. 목표는 제목(B 13) + 본문 첫 글줄(두 줄까지). 조건은 「2.」 번호 + 글 한 줄, 미검증은 오른쪽에 근거 상태(실패만 `Theme.Evidence.fail`). 다섯 개 넘으면 「외 N개」. 비면 「없음」. 메모는 작성 시점(이후 변경이 있으면 `liveText`) + 메모 세 줄.
- 버튼 줄: 왼쪽 결과(「복사됨」✓ `done`, 「복사 실패」·「터미널 열기 실패 · 문맥은 복사됨」 `liveText`), 오른쪽 「닫기」, 「Claude Code에서 열기」(bordered, 실행 파일·Terminal.app·작업 폴더가 확인될 때만), 「Claude Code용 문맥 복사」(기본 버튼). 복사가 기본 동작이고 열기는 덧붙인 단축이다.

## Mac 창 틀

- `NavigationSplitView` 두 칸 + 오른쪽 `inspector`. 창 틀을 직접 그리지 않는다(신호등 버튼, 툴바는 시스템 것).
- 사이드바: 시스템 사이드바 목록. 항목은 대시보드, 그 아래 「프로젝트」 구역에 프로젝트 이름 + 작업중 개수(점과 숫자). 배경 `sidebar`. 아이콘 색은 `liveText`.
- 툴바: 화면 이름, 검색 필드(`.searchable`), 프로젝트 등록(+), 인스펙터 토글.
- 목록은 표 형태: 열 머리 11pt semibold `textMuted` + 아래 구분선, 행 높이 32–34, 프로젝트별 그룹 머리 11pt semibold. 강조할 행(작업중)만 `surface` 배경.
- 최근 기록·카드 정보처럼 곁들이는 정보는 인스펙터(`bgPanel`, 너비 약 300). 프로젝트 보드에서는 닫힌 채 시작하고 툴바 토글로 연다(연 상태는 앱을 끌 때까지 기억). 통합 대시보드는 닫힌 채, 카드 상세·지침 문서는 열린 채.
- 프로젝트 보드: 네 칸이 폭을 똑같이 나눠 늘어나고, 칸 최소 폭은 220. 창이 좁거나 인스펙터를 열어 그보다 좁아지면 칸을 줄이지 않고 보드를 가로로 넘긴다. 칸 안쪽 여백 가로 10·세로 12, 카드·세션 타일 안쪽 여백 가로 10·세로 12(`Theme.Board`). 1280pt 창(인스펙터 닫힘)에서 칸은 약 240.
- 페이지 제목은 본문 맨 위 나눔스퀘어라운드 B 26. 툴바 제목과 겹쳐도 된다(툴바는 화면 이름, 본문 제목은 상황 문장).
- 앱 accent 색은 `liveText`.
- 사이드바 맨 아래 사용량 게이지: 도구별 묶음 「Claude」「Codex」(이 순서). 묶음 머리는 11pt bold `textMuted`, 묶음 사이 `Spacing.l`. 한도마다 한 줄: 「5시간」「7일」 캡션 + 높이 4 캡슐 막대(채움 `live`, 바탕 `gaugeTrack` 12%) + 오른쪽 「42%」, 그 아래 막대 시작선에 맞춰 초기화 시각 「↻ 오후 3:20」(캡션 `textMuted`, 아이콘 `arrow.clockwise`; 오늘은 시각, 내일은 「내일 오전 9:00」, 그 뒤는 「10월 7일」, 모르거나 지났으면 생략). 80% 이상은 막대·숫자를 `liveText`로 진하게, 30분 넘은 기록은 묶음째 불투명도 0.45, 기록이 없거나 설정에서 끈 도구는 묶음째 숨긴다. 묶음에 마우스를 올리면 「12분 전 기준」.
- 설정 창(⌘,): grouped `Form` 너비 380, 「사용량」 구역에 「Claude」「Codex」 토글 두 개(기본 켬).

### PC 상태 갱신 (2026-09-30)

- 보드·통합 대시보드·사이드바·카드 상세는 저장 알림과 로컬 훅/MCP 처리 직후 현재 시각으로 다시 계산한다. 순수 시간 변화는 5초 주기로 확인한다.
- 끊긴 프로세스와 어긋난 연결 정리는 10초 주기. 카드 자동 완료나 무조건 세션 종료는 하지 않는다.
- 마지막 연결 카드가 완료됐고 이후 새 사용자 요청이 없다면, 대화가 열려 있어도 카드 없는 세션 타일은 표시하지 않는다. 진행 중인 하위 작업이 있거나 새 요청이 오면 다시 표시한다. 완료·이벤트 기록은 유지한다.

## iPhone

한 화면(`iOS/RootView`, `NavigationStack`), 내비게이션 막대는 숨긴다. 좌우 여백 18, 구역 사이 18.

- 머리: 날짜(「9월 28일 일요일」 13 `textMuted`) 아래 제목 「작업중 N」(N = live 줄 수, 없으면 「진행 중인 작업 없음」), 나눔스퀘어라운드 B 30. 개발용은 날짜 줄 오른쪽에 「Dev」.
- 작업중: Mac 대시보드와 같은 줄(`DashboardQuery`) 하나가 카드 한 장. 프로젝트 순서대로 이어 놓고(live 있는 프로젝트 먼저, 이름순) 프로젝트 이름은 카드 윗줄에 둔다. 윗줄 「LDG-14 · 가계부 앱」(모노 11 `textMuted`) + 오른쪽 경과(12 B `liveText`) 또는 「멈춤 N분」(12 `textMuted`), 제목 15 B, 아랫줄 「sess·7f2a · ReceiptParser.swift」(모노 11 `textSecondary`). live는 `live` 1.5pt 테두리와 펄스 점, 멈춤은 `border` 1pt와 속 빈 점. 서브에이전트 줄은 16 들여쓴다. 카드 없는 세션은 윗줄에 프로젝트 이름만, 제목 자리에 마지막 요청 문장(없으면 「카드 없음」, 15 R `textMuted`, 두 줄까지), 누를 수 없다. 카드 사이 10, 안쪽 여백 14, 모서리 14, 흰 바탕.
- 방금 기록된 아이디어: 구역 제목 14 B. 최근 7일에 생긴 idea 상태 카드(`IdeaInbox`, 새것부터). 점선(`ideaBorder` 1.5, 5·3) `bgPanel` 카드에 「LDG-21 · 18분 전」, 제목, 알약 버튼 「다음 할 일로」「보관」(높이 36, 13 B, 흰 바탕·`border`). 누르면 바로 옮기고 목록에서 빠진다.
- 카드를 누르면 상세(읽기 전용): 「LDG-14 · 가계부 앱 · 다음 할 일」, 제목 22 B, 본문 15, 「완료 조건 1/3」과 체크 표시(`checkmark.square` `done` / `square` `textMuted`, 끝난 것은 취소선).
- 시간 표시는 30초마다 다시 그린다(`TimelineView`). 당겨서 새로고침은 없다(동기화가 알아서 온다).

## 화면 문구

- 설명서 말투, 동작 규칙, 만든 쪽 용어(훅·MCP·스킬·세션 요약 등)를 화면에 쓰지 않는다. 시안에 있는 「Claude가 남긴 것」, 「대화에서 감지」, 「세션 종료 시 자동 작성」, 「새 세션을 열어 …」 같은 문구는 옮기지 않는다.
- 세션 ID·서브에이전트 이름·파일명처럼 사실만 짧게 보인다.

### 타이포

- 제목·본문·UI: 나눔스퀘어라운드(NanumSquareRound). 한글까지 둥글게 그려지는 서체라 번들한다. 시스템 둥근 서체(SF Pro Rounded)에는 한글 글리프가 없다.
- 굵기 대응: 본문 regular → R, medium·semibold → B, 페이지 제목·카드 상세 제목 → B. L·EB는 번들만 하고 쓰지 않는다. 가짜 볼드 금지.
- 카드 ID, 세션 ID, 경로, 파일명: 모노 (SF Mono). 그대로 둔다.
- 크기(macOS): 페이지 제목 26, 카드 상세 제목 28, 섹션 13, 본문 13, 표 머리·캡션 11, 큰 캡션 11.5, 카드 제목 14. 크기는 고정(Dynamic Type 미적용).
- 새 프로젝트 등록 창: 제목 26(B), 입력 14, 이름표 12(`textSecondary`), 입력 칸 높이 36·모서리 8, 키 칸 폭 110, 상자 제목 13(B). `Theme.Init`.
- 지침 문서 읽기: 제목 1·2·3단계 22·17·14.5(B), 본문 13.5, 인라인 코드 12.5 모노, 코드 블록 12 모노, 편집기·비교 원문 12.5 모노. `Theme.Guide`.
- 큰 캡션만 12에서 11.5로 줄였다. 이 서체는 숫자 폭이 고정이라 「12분째」 같은 경과 시간이 SF보다 넓다.
- 파일: `App/Fonts/NanumSquareRound{L,R,B,EB}.ttf`, 라이선스 `App/Fonts/OFL.txt`(SIL OFL 1.1, NAVER). 앱 시작 시 `FontRegistry`가 프로세스 범위로 등록하고, 등록에 실패하면 시스템 폰트로 그려진다.

### 형태

- 모서리: 카드 10, 패널 12–14, 버튼 8, 배지 캡슐.
- 작업중 카드: 1.5pt `live` 테두리 + 옅은 그림자. 서브에이전트 카드는 부모 아래 14pt 들여쓰기.
- 작업중 점: 8pt 원, 1.8초 주기 펄스(바깥으로 퍼지는 링).
- 이모지·그라디언트 사용 안 함. 아이콘은 SF Symbols 선형.

## 상태 표현 규칙

| 상태 | 표현 |
|---|---|
| 아이디어 | 점선 테두리, `bgPanel` 배경 |
| 다음 할 일 | 흰 카드, 파란 점 헤더 |
| 작업중 | 클레이 테두리, 펄스 점, 세션 정보 박스(세션 종류·ID·최근 파일) |
| 멈춤 | 작업중 레이아웃 + 속 빈 점(`liveText` 1.5pt 테두리, 펄스 없음) + "멈춤 N분" |
| 카드 없는 세션(보드 작업중 칸) | 카드 아래, 흰 바탕 `border` 1pt(그림자·클레이 테두리 없음). 제목 자리에 마지막 요청 문장(14 R `text`, 두 줄까지, 마우스를 올리면 전체), 없으면 「카드 없음」(14 R `textMuted`). 그 아래 한 줄: 점 + `sess·7f2a`(모노 11 `textSecondary`) + 오른쪽 경과(11.5 B `liveText`)/「멈춤 N분」(11.5 `textMuted`). 경과는 마지막 요청부터이고 요청 시각이 없으면 비운다. 경과는 잘리지 않고, 한 줄에 안 들어가면 세션을 아래 줄로 내린다. 최근 파일이나 서브에이전트가 있으면 그 아래 상자(`bg`)에 최근 파일(모노 11, 가운데 생략) + 오른쪽 `arrow.triangle.branch` + 수. 누를 수 없다 |
| 완료 | 흰 카드, 불투명도 0.85, 날짜·세션 횟수 |
