# 디자인

원본 캔버스: https://claude.ai/artifact/G9JsAmHhuKb1ZLeRdoroGM

`design/*.dc.html`은 캔버스 전용 런타임으로 그려지는 마크업이라 브라우저에서 단독으로 열리지 않는다. **레이아웃 구조, 인라인 스타일 값, 문구를 읽는 용도**로 쓴다. SwiftUI로 옮길 때 픽셀 단위 복제보다 구조와 토큰을 따른다.

## 통합 대시보드

토큰 `Theme.Dashboard`·`Theme.Situation`.

- 머리말 아래 한 줄(`DashboardOverview.headline`): 「1개 프로젝트에서 작업 중, 2개 세션이 내 답을 기다립니다.」 한쪽만 있으면 그쪽만, 둘 다 없으면 「진행 중인 작업이 없습니다.」
- 상단 칸: 작업 중 · 대기·활동 없음(열린 카드 연결과 카드 없는 메인 세션 줄 수) · 다음 할 일 · 오늘 완료(로컬 자정부터). 검색·필터와 무관한 전체 집계. 내 답(승인·질문)을 기다리는 줄이 있으면 「작업 중」과 「대기·활동 없음」 사이에 「내 답 기다림」 칸(숫자 `waitingText`)이 생기고 그 줄은 「대기·활동 없음」에서 빠진다. 다섯 칸은 900 창에서도 한 줄.
- 중앙: 진행 중인 작업 타일, 전체/Claude/Codex 필터. 카드 제목·ID, 프로젝트, 도구·세션, 최근 파일, 경과. 하위 작업은 부모가 보이면 들여쓴다. 카드가 있으면 상세로, 카드 없는 세션은 읽기만.
- 오른쪽: 「내 답 기다림 N개」(접지 않음, 「승인 대기 3분」·「질문 대기 3분」은 `waitingText`, 카드 없는 서브에이전트가 기다리면 부모 줄에 「승인 대기 3분 · test-writer」), 접을 수 있는 「대기·활동 없음 N개」, 미완료 카드의 다음 세션 메모(최근 수정순 3개), 접힌 최근 기록(3개).
- 본문 폭 780 이상이면 작업/이어가기 두 열, 좁으면 위아래.
- 기록 인스펙터는 닫힌 채 시작한다. 검색은 프로젝트 이름·키, 카드 제목·ID, 카드 없는 세션의 요청 문장에 걸린다. 비면 빈 상태 문구.

### 상황판

맨 아래 프로젝트 타일 격자. 규칙은 `docs/SPEC.md` 「대시보드 상황판」. 순서는 나를 기다리는 프로젝트 → 작업 중 → 최근 활동순.

- 격자: 타일 최소 폭 300(`tileMinWidth`), 1~3열(`maxColumns`), 사이 `Spacing.l`. 1440 창은 3열, 900 창은 2열.
- 타일: `surface`, `border` 1pt, `Radius.panel`, 안쪽 `Spacing.l`, 구역 사이 `sectionGap`, 줄 사이 `rowGap`.
- 머리: 키(모노 10 `textMuted`) · 이름(14 B) · 작업중 점 … 오른쪽 마지막 활동(캡션 11 `textMuted`)과 `chevron.right`.
- 나를 기다림: 알약 「승인 기다림 1」「질문 기다림 1」 11.5 B `liveText`, 바탕 `liveBg`, `Radius.badge`. 없으면 줄이 없다.
- 지금 상황: `bgPanel` 상자(`Radius.box`, 여백 `Spacing.m`), 본문 13 `textSecondary` 4줄(`statusLines`), 아래 「34분 전 · Claude Code」 + 「오래됨」(11.5 B `textMuted`) + 오른쪽 「더 보기」/「접기」(11.5 B `liveText`). 오래되면 상자째 불투명도 0.5(`staleOpacity`).
- 구역 머리 「진행 중 1」「다음 11」「최근 끝냄 39」 11 B `textMuted`. 카드 줄: (진행 중이면 점) + ID(모노 10, 폭 64) + 제목(13, 한 줄) + 오른쪽 도구·「멈춤 · 도구」 또는 끝낸 시각. 멈춘 줄 제목은 `textSecondary`.
- 아래 줄: 「정리 안 된 작업 N」(11.5 B `liveText`) · 「아이디어 N」(캡션 `textMuted`).
- Debug 실행 인자: `-WaypointWindowSize 1440x900`, `-WaypointDashboardScroll board`.

## 카드 상세

### 완료 근거

토큰 `Theme.Evidence`.

- 완료 조건 줄 오른쪽에 근거 상태(11.5): 「통과 · 확인됨」「실패 · 보고」「미검증」「변경 후 미검증 · 확인됨」「건너뜀 · 보고」. 통과 `done` B, 실패 `liveText` B, 나머지 `textMuted` R. 마우스를 올리면 명령과 시각. 체크 상자는 사용자 판단 표시로 따로 둔다.
- 「검증 기록」(완료 조건 아래, 히스토리 위, 없으면 그리지 않음): 최근 8줄, 넘으면 「N개 더」. 줄: 결과(폭 64, 결과 색) + 명령(모노 12, 가운데 생략) + 오른쪽 캡션 「조건 1 · 확인됨 · 이후 변경 · 14:02」.
- 히스토리·활동 탭에도 「검증 통과 · 확인됨」「조건 2 검증 실패 · 보고」 줄이 남는다.

### 재개

토큰 `Theme.Resume`.

- 「작업 이어가기」 영역: 제목 줄(「재개 문맥 준비」) 아래 재개 상태(11.5) 「준비됨」「복사함 · Codex 새 세션 연결 전」「연결됨 · Codex 새 세션」「연결 끊김 · Codex」「재개 불가 · 완료한 카드」. 연결됨만 `done`. 그 아래 메모 작성 시점과 메모 세 줄.
- 재개 창(720×640): 제목 → 요약 묶음(`bgPanel`, 반경 12, 안쪽 14) → 접힌 「복사할 문맥」(모노 12, `bgSunken`) → 도구 고르기 → 작업 폴더(모노) → 재개 상태 → 버튼 줄. 요약과 문맥은 같이 스크롤한다.
- 요약 묶음은 두 칸 표: 왼쪽 「목표」「남은 조건 N」「미검증 N」「메모」(11.5 B `textMuted`, 폭 76), 오른쪽 내용. 다섯 개 넘으면 「외 N개」, 비면 「없음」. 메모 작성 시점은 이후 변경이 있으면 `liveText`.
- 버튼 줄: 왼쪽 결과(「복사됨」✓ `done`, 「복사 실패」·「터미널 열기 실패 · 문맥은 복사됨」 `liveText`), 오른쪽 「닫기」, 「Claude Code에서 열기」(bordered, 열 수 있을 때만), 「Claude Code용 문맥 복사」(기본 버튼).

## 지침 화면

토큰 `Theme.Guidance`·`Theme.GuideItems`.

- 사이드바 「지침」(`text.book.closed`). 본문은 왼쪽 출처 목록(폭 240–300, `bgPanel`) | 오른쪽 내용.
- 목록 묶음 순서: 「전역」(Claude, Codex) → 상위 폴더(「~/workspace」) → 프로젝트(이름 + 키 모노 10) → 「다른 폴더」 → 맨 아래 「지운 파일」. 줄은 이름(모노 12, 가운데 생략) 아래 캡션 「Claude · 26줄」「Codex · 규칙 33」「항목 3」. 기억은 묶음마다 접힌 「기억 12」 한 줄, 기억 파일 줄은 이름(13 B) 아래 설명(13 `textSecondary`).
- 내용 위 한 줄(`bgPanel`, 높이 34): 경로(모노 12) · 열린 세션 「열린 Claude 세션 3」(`liveText`) · 사실(`textMuted`) · 「백업 N」(있을 때만) · 「읽기 | 항목」. 규칙 파일이고 `codex`가 없으면 「codex 없음 · 간단 검사」.
- 읽기: Markdown은 지침 문서 읽기 화면(목차 포함), frontmatter는 위에 모노 11.5 `bgSunken` 띠. 명령 규칙은 원문(모노 12.5). Codex 기억은 「항목 N」 아래 대화 ID·시각·앞부분, 50개 넘으면 「N개 더」. 읽지 못하면 「읽을 수 없음」. 찾은 것이 없으면 「찾은 지침 없음」.
- 프로젝트 지침 문서 화면의 전환은 「읽기 | 항목 | 편집」. 인스펙터에 「이 프로젝트에 걸린 지침」(줄 높이 26, 이름 모노 12 + 「Claude · 상위 폴더」, 등록된 파일은 「등록됨」 `done`).
- 항목 보기: 본문 폭 760까지. 절 머리 11.5 B `textMuted`(위 여백 14), 항목 한 줄씩(본문 13.5), 하위 항목은 단마다 20 들여쓴다. 표·코드·frontmatter·명령 규칙은 원문 모노 12(코드는 4줄까지). 항목이 없으면 「항목 없음」.
- 마우스를 올린 줄만 `surface`(반경 6) + 옅은 그림자, 오른쪽에 고치기(연필 `textMuted`)·지우기(휴지통 `liveText`) 아이콘(12, 누르는 칸 24). 버튼 자리는 늘 잡아 둔다.
- 고치기: 줄이 원문 편집 상자(모노 12.5, 흰 바탕, `live` 1.5 테두리, 높이 56–320)로 바뀌고 「취소」「저장」. ⌘↩ 저장, Esc 취소. 저장이 막히면 「저장 못 함 · …」「저장 안 함 · 줄 2 · …」「검사 못 함」「바뀜」 + 「다시 읽기」(`liveText`), 상자는 열린 채.
- 지우기: 화면 아래 가운데 어두운 알림(`#141413` 92%, 반경 8) 「지움 · 앞부분」(+「· 하위 N개 포함」「· 색인 줄 포함」) + 「되돌리기」. 6초 뒤 사라진다. 되돌리지 못하면 「되돌리지 못함 · 바뀜」.
- 「백업 N」 창: 위 경로, 왼쪽 사본 목록(폭 220 `backupListWidth`, 「10:02:03 · 지우기 전」), 오른쪽 원문(모노 12.5), 아래 「닫기」「이 판으로 되돌리기」. 지운 파일도 같은 창.
- Debug 실행 인자: `-WaypointGuideMode items`, `-WaypointGuideItemsEdit N`, `-WaypointGuidanceSource <경로 끝>`.

## Mac 창 틀

- `NavigationSplitView` 두 칸 + 오른쪽 `inspector`. 창 틀을 직접 그리지 않는다(신호등 버튼, 툴바는 시스템 것).
- 사이드바: 시스템 사이드바 목록. 항목은 대시보드·지침, 그 아래 「프로젝트」 구역에 프로젝트 이름 + 작업중 개수(점과 숫자). 작업중이 없고 멈춘 것만 있으면 속 빈 점과 멈춤 수. 내 답을 기다리는 세션이 있으면 점 대신 그 수가 든 알약(`waitingBackground`·`waitingText`)만 그린다. 배경 `sidebar`. 아이콘 색은 `liveText`.
- 툴바: 화면 이름, 검색 필드(`.searchable`), 프로젝트 등록(+), 인스펙터 토글.
- 목록은 표 형태: 열 머리 11pt semibold `textMuted` + 아래 구분선, 행 높이 32–34, 프로젝트별 그룹 머리 11pt semibold. 강조할 행(작업중)만 `surface` 배경.
- 최근 기록·카드 정보처럼 곁들이는 정보는 인스펙터(`bgPanel`, 너비 약 300). 프로젝트 보드에서는 닫힌 채 시작하고 툴바 토글로 연다(연 상태는 앱을 끌 때까지 기억). 통합 대시보드는 닫힌 채, 카드 상세·지침 문서는 열린 채.
- 프로젝트 보드: 네 칸이 폭을 똑같이 나눠 늘어나고, 칸 최소 폭은 220. 창이 좁거나 인스펙터를 열어 그보다 좁아지면 칸을 줄이지 않고 보드를 가로로 넘긴다. 칸 안쪽 여백 가로 10·세로 12, 카드·세션 타일 안쪽 여백 가로 10·세로 12(`Theme.Board`). 1280pt 창(인스펙터 닫힘)에서 칸은 약 240.
- 페이지 제목은 본문 맨 위 나눔스퀘어라운드 B 26. 툴바 제목과 겹쳐도 된다(툴바는 화면 이름, 본문 제목은 상황 문장).
- 앱 accent 색은 `liveText`.
- 사이드바 맨 아래 사용량 게이지: 도구별 묶음 「Claude」「Codex」(이 순서). 묶음 머리는 11pt bold `textMuted`, 묶음 사이 `Spacing.l`. 한도마다 한 줄: 「5시간」「7일」 캡션 + 높이 4 캡슐 막대(채움 `live`, 바탕 `gaugeTrack` 12%) + 오른쪽 「42%」, 그 아래 막대 시작선에 맞춰 초기화 시각 「↻ 오후 3:20」(캡션 `textMuted`, 아이콘 `arrow.clockwise`; 오늘은 시각, 내일은 「내일 오전 9:00」, 그 뒤는 「10월 7일」, 모르거나 지났으면 생략). 80% 이상은 막대·숫자를 `liveText`로 진하게, 30분 넘은 기록은 묶음째 불투명도 0.45, 기록이 없거나 설정에서 끈 도구는 묶음째 숨긴다. 묶음에 마우스를 올리면 「12분 전 기준」.
- 설정 창(⌘,): grouped `Form` 너비 380, 「사용량」 구역에 「Claude」「Codex」 토글 두 개(기본 켬).

## iPhone

### 형태

- 모서리: 카드 10, 패널 12–14, 버튼 8, 배지 캡슐.
