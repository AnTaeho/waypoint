# 구현 순서

각 마일스톤이 끝나면 멈추고 사용자에게 확인받는다. 완료 조건은 전부 충족해야 다음으로 간다.

## M0 — 저장소 뼈대

- Xcode 멀티플랫폼 앱(macOS 14+, iOS 17+), SwiftUI + SwiftData.
- 공유 모델은 `Shared/` 패키지(또는 폴더)로 분리.
- **완료 조건:** 두 플랫폼 빌드 성공, 빈 창이 뜬다.

## M1 — 데이터 모델과 Mac UI (정적)

- `SPEC.md` 4장의 모델 구현. 미리보기용 샘플 데이터 시더.
- 대시보드, 프로젝트 보드, 카드 상세 화면을 `design/` 시안대로 구현. 카드 드래그로 상태 이동.
- **완료 조건:** 샘플 데이터로 세 화면이 시안과 같은 구조로 보이고, 카드 이동이 저장된다.

## M2 — 훅 수신과 실시간 "작업중"

- 앱 내장 로컬 서버(`127.0.0.1:47821`), `/hooks/*` 엔드포인트.
- `integration/hooks/waypoint-hook.sh` 완성, outbox 흡수.
- 세션 생명주기, stalled 판정 타이머, 메뉴 막대 상주.
- **먼저 할 일:** 모든 훅 입력을 그대로 파일에 로깅하는 모드로 실제 필드를 확인하고 SPEC 5장을 갱신.
- **완료 조건:** 등록된 폴더에서 Claude Code를 2개 띄우면 대시보드에 해당 프로젝트 세션 2개가 live로 보이고, 종료하면 사라진다. 앱을 끈 채 세션을 돌린 뒤 앱을 켜면 기록이 반영된다.

## M3 — MCP 도구와 tracker 스킬

- `/mcp` 엔드포인트, SPEC 7장 도구.
- `integration/skills/tracker/SKILL.md` 다듬기, 설치 안내.
- **완료 조건:** 실제 세션에서 "LDG-17 하자" → 카드가 작업중, "나중에 CSV도" → 아이디어 카드 생성, 세션 종료 시 다음 세션 메모 저장. 서브에이전트 작업이 하위 카드로 작업중 표시.

## M4 — 지침 문서

- GuideDoc 등록, Markdown 렌더링, 편집, FSEvents 양방향 동기화, 충돌 비교 화면, 버전 기록.
- **완료 조건:** 앱에서 고치면 로컬 파일이 바뀌고, 에디터에서 고치면 앱이 바뀐다. 동시 변경 시 비교 화면이 뜬다.

## M5 — 프로젝트 init

- `project_init` 도구 → 앱 확인 시트(시안 `Init.dc.html`) → 등록.
- 스킬의 `/tracker init` 흐름.
- **완료 조건:** 새 폴더에서 `/tracker init` 한 번으로 프로젝트·지침 문서·초기 카드가 생긴다.

## M6 — iPhone과 CloudKit

- CloudKit 동기화, iOS 작업중 화면(시안 `iPhone.dc.html`), 아이디어 카드 분류(다음 할 일로 / 보관).
- **완료 조건:** Mac에서 시작한 세션이 수 초~수십 초 내 iPhone에 작업중으로 보인다.

## 이후 후보

- 위젯 / Live Activity로 작업중 표시
- 활동 기록 전용 화면 (프로젝트별 타임라인)
- 여러 Mac 지원
