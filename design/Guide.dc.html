가계부 앱 — Claude 작업 지침

개요

SwiftUI + SwiftData 기반 iOS 17 이상 앱. 외부 의존성은 최소화하고 Apple 프레임워크를 먼저 검토한다.

코드 스타일

  • View 파일이 150줄을 넘으면 하위 View로 분리
  • 한국어 주석 허용, 공개 API에는 문서 주석
  • 금액은 Decimal만 사용, Double 금지

테스트

파서류는 Tests/Fixtures의 샘플 영수증으로 검증한다. 완료 처리 전 반드시 실행:

xcodebuild test -scheme Ledger \
  -destination 'platform=iOS Simulator,name=iPhone 16'

트래커 연동

  • 작업을 시작하기 전에 해당 카드를 작업중으로 전환
  • “나중에”, “언젠가” 같은 언급은 아이디어 카드로 기록
